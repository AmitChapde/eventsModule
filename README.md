# Events Module

A simple fullstack Events module built with React, Node.js, Express and MongoDB.

## Features

- Browse upcoming events
- View event details
- Create an event
- Edit an event
- RSVP to an event
- Responsive UI
- REST API
- MongoDB persistence

## Tech Stack

### Frontend

- React
- React Router
- CSS Modules
- Vite

### Backend

- Node.js
- Express
- MongoDB
- Mongoose
